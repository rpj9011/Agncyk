## Brand & Style

The brand identity centers on the intersection of high-end engineering and strategic expansion. It targets ambitious founders and enterprise leaders who value performance-driven results over purely aesthetic exercises. The emotional response is one of calculated confidence, stability, and surgical precision.

This design system employs a **Corporate / Modern** aesthetic with a **Minimalist** skeletal structure. It utilizes heavy "engineered" influences through thin hairline borders, monospaced-adjacent UI details, and a high-contrast dark theme. The visual language conveys "Conversion-First Architecture" by prioritizing information density and quantitative proof points through a rigorous, grid-based layout.

## Colors

The palette is anchored in a deep, midnight environment to establish a premium and technical baseline. 

- **Primary (Electric Gold):** Used sparingly for high-intent CTAs and growth indicators. It represents value and luxury.
- **Secondary (Midnight Blue):** Used for surface-level differentiation and subtle container backgrounds to add depth to the pure black base.
- **Tertiary (Off-White):** Reserved for primary readability and high-contrast typography.
- **Cobalt Accent:** Utilized for interactive states, focus indicators, and technical details (like code snippets or engineering tags) to reinforce the "architectural" theme.
- **Success Growth:** A vibrant green specifically for positive performance metrics and upward-trending data visualizations.

## Typography

The typographic strategy pairs a high-authority serif for narrative growth with a high-precision sans-serif for technical execution.

- **Headlines:** Use **Playfair Display** for hero statements and section titles. It injects a "premium boutique" feel into the technical environment. It should often be paired with italicized keywords for emphasis.
- **UI & Body:** Use **Inter** for all functional text, descriptions, and data points. Its neutral, systematic nature ensures clarity in dense layouts.
- **Metrics:** Quantitative data (e.g., "+187%") should use **Inter** with heavy weights and tight letter-spacing to appear "engineered" and impactful.
- **Labels:** Use uppercase Inter for category tags (e.g., SAAS, E-COMMERCE) to create clear information hierarchy.

## Layout & Spacing

This design system uses a **Fixed Grid** philosophy for desktop (12 columns) and a **Fluid Fluid** approach for mobile (4 columns).

- **Grid:** Layouts are strictly aligned to a 4px baseline grid to maintain "engineering" precision.
- **Rhythm:** Generous vertical section gaps (120px+) create a "gallery" feel for the portfolio, allowing each project to breathe.
- **Mobile Reflow:** For the mobile portfolio, 3-column service grids collapse to a single column stack, while metric highlights (3-across) scale down their font size but remain in a tight horizontal row or a 2x2 grid to maintain density.
- **Margins:** Desktop uses a wide 80px side margin, while mobile utilizes a tighter 16px margin to maximize screen real estate for technical data.

## Elevation & Depth

To maintain a "technical" and "flat" architecture, this design system avoids heavy shadows in favor of **Tonal Layers** and **Low-Contrast Outlines**.

- **Surface Levels:** The base is `#0F0F0F`. Cards and secondary containers use `#1A2333` with a very subtle 1px border in `#808080` (at 20% opacity).
- **Interactive Depth:** When a card is hovered, the border color shifts to the Primary Gold or Cobalt Blue, rather than lifting with a shadow. This reinforces the "engineered" tactile response.
- **Glassmorphism:** Reserved exclusively for the sticky navigation bar and mobile overlays. Use a `backdrop-filter: blur(12px)` with a semi-transparent `#0F0F0F` background to maintain context while scrolling.

## Shapes

The shape language is sharp and disciplined. We use **Soft (0.25rem)** roundedness for standard UI components like inputs and buttons to prevent the interface from feeling "aggressive," yet it remains much tighter than consumer-facing "rounded" apps. 

- **Sharp Corners:** Large section containers and image carousels should retain 0px (sharp) corners to emphasize the grid-based architecture.
- **Pill Tags:** Small category labels can use full-pill rounding to distinguish them as "meta-data" rather than structural elements.

## Components

### Buttons
- **Primary:** Background in Primary Gold, text in Deep Black. Sharp corners. Hover state includes a slight horizontal expansion of the trailing arrow (→).
- **Secondary/Ghost:** 1px border in Tertiary Off-White. Text in Off-White. Fills with Cobalt Blue on hover.

### Cards (Selected Work)
- **Architecture:** Full-width or 2-column grid. Imagery is primary, followed by a Label-caps category and a Headline-md title. 
- **Hover:** Subtle zoom on imagery with a color-shift on the border hairline.

### Form Inputs
- **Style:** Underline-only or subtle outlined box. Background is slightly lighter than the page base.
- **Active State:** Border shifts to Cobalt Blue with a monospaced "Focus Active" label appearing in the top right corner.

### Metric Blocks
- **Composition:** Large `metric-num` value in the center, followed by a `label-caps` description below. These should be separated by thin vertical hairline dividers when placed in a row.

### Lists
- **Numbered Process:** Use large, low-opacity serif numbers (01, 02) as background elements behind the Inter-body text to signify the "Engineering Process."
